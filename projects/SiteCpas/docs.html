🎫

Connexion & accès

Comment se connecter et gérer son compte

  1. Ouvrir l'application Allez sur l'adresse fournie par votre administrateur. Favorisez Chrome ou Firefox à jour.
  2. Sélectionner votre nom Choisissez votre nom dans la liste des agents. Si vous n'apparaissez pas, contactez l'admin.
  3. Entrer votre code Votre administrateur vous a communiqué un code personnel à 4 chiffres minimum. Gardez-le secret.
  4. Premier accès La mascotte vous guidera dans une courte présentation des fonctionnalités de votre poste.
Mot de passe oublié ? Contactez votre administrateur — il peut réinitialiser votre code depuis les paramètres.
L'application fonctionne sans installation. Ajoutez-la à votre bureau : dans Chrome, cliquez sur ⋮ → Installer moncompagnon.
🔔

Notifications

Comment lire et gérer vos alertes

🚨

Alerte (rouge)

Message urgent — action immédiate requise. Son triple bip.

⚠️

Avertissement (orange)

Information importante mais non urgente. Son double bip.

ℹ️

Info (bleue)

Notification informative standard. Son discret.

💬

Répondre

Certaines notifications permettent de répondre directement — cliquez sur "Répondre".

  1. Accéder aux notificationsCliquez sur la cloche 🔔 en haut à droite. Un badge rouge indique les non-lues.
  2. Lire et archiverLes notifications récentes sont affichées. Cliquez sur ✕ pour archiver, ou utilisez "Tout marquer lu".
  3. Répondre à une demandeSi un collègue vous a contacté via le panneau Interventions ou Requête, vous pouvez lui répondre directement.

FAQ

Questions fréquentes

  1. L'application ne se charge pasVérifiez votre connexion internet. Essayez de vider le cache du navigateur (Ctrl+Shift+R). Si le problème persiste, contactez l'admin.
  2. Mon nom n'apparaît pas dans la listeVotre administrateur doit d'abord vous créer un compte depuis les Paramètres → Gestion des agents.
  3. Je n'entends pas les sons de notificationVérifiez que le son de votre ordinateur n'est pas coupé. Les sons utilisent l'API audio du navigateur — ils fonctionnent sans extension.
  4. Ma file d'attente affiche 0 alors qu'il y a des gensVérifiez que votre bureau est ouvert (bouton "Ouvrir bureau" en haut). Un bureau fermé n'accepte pas de tickets.
  5. Je ne vois pas le bouton StatistiquesLes stats sont réservées aux rôles admin, direction et chef de service. Contactez votre administrateur si vous pensez y avoir accès.

Matériel complémentaire

Équipements recommandés pour tirer le meilleur de moncompagnon — à discuter avec votre intégrateur

Important : La sélection et l'installation du matériel doit être discutée avec votre intégrateur ou prestataire informatique. Il connaît votre infrastructure et pourra vous conseiller les options les mieux adaptées à votre contexte.
🖨️

Imprimante tickets Recommandé

Une imprimante thermique Epson TM-T20 (ou série TM) est idéale pour imprimer les tickets numérotés. Compatible réseau, silencieuse, et sans encre — elle s'intègre directement avec le module tickets de moncompagnon.

📋

Alternative : tickets nominatifs

Si vous ne souhaitez pas d'imprimante physique, moncompagnon supporte les tickets nominatifs : le bénéficiaire donne son nom à l'accueil, il est appelé par son prénom sur l'écran public. Aucun matériel supplémentaire nécessaire.

🖥️

Écrans publics en salle d'attente Recommandé

Un ou plusieurs écrans affichant la vue publique de moncompagnon (numéros appelés, bureaux disponibles). N'importe quel téléviseur ou moniteur avec navigateur web fait l'affaire — connecté en Wi-Fi ou câble Ethernet.

📟

Borne tactile kiosque Optionnel

Une tablette ou un écran tactile sur pied permet aux bénéficiaires de prendre eux-mêmes un ticket en choisissant leur service. Recommandé si l'accueil est souvent surchargé ou absent. Si un agent d'accueil est toujours présent, la borne est optionnelle.

💻

Postes agents

Chaque agent doit disposer d'un ordinateur, d'une tablette ou d'un smartphone avec un navigateur web récent (Chrome ou Firefox recommandé). moncompagnon fonctionne entièrement dans le navigateur — aucune installation requise.

📶

Réseau & connectivité

Une connexion Wi-Fi stable ou câble Ethernet est nécessaire pour tous les postes. moncompagnon est hébergé sur Firebase (Google) — aucun serveur local à maintenir.

Conseil intégration : Discutez avec votre intégrateur du câblage réseau pour les écrans publics et la borne kiosque, et de la compatibilité réseau de votre imprimante Epson. La configuration matérielle se fait une seule fois — moncompagnon gère le reste.
🌟

Guide — Agent d'accueil

Tu es en première ligne. Voici tout ce qu'il faut savoir pour gérer ton poste.

🎫

Émettre un ticket

Depuis la Vue Direct, sélectionnez le groupe de file et cliquez "Émettre un ticket". Le numéro s'affiche sur la vue publique automatiquement.

👥

Voir les statuts équipe

La Vue Direct → onglet Équipe montre qui est disponible, dans quel bureau, absent ou en route.

📢

Diffuser un message

Bouton "📢 Diffuser" dans le header. Sélectionnez les rôles destinataires et envoyez votre message en 3 secondes.

📋

Vue Direct complète

Voyez tous les bureaux, leur taux d'occupation, les tickets en attente et les agents présents — tout en une page.

Routine du matin

  1. Ouvrir l'application & se connecterLa mascotte vous accueille avec les infos du jour (météo, messages).
  2. Activer la Vue DirectBouton "📋 Direct" dans le header. C'est votre vue principale pour la journée.
  3. Vérifier les bureaux ouvertsChaque agent doit avoir ouvert son bureau. Si un bureau est vide, contactez l'agent concerné.
  4. Commencer l'accueil des bénéficiairesÉmettez les tickets au fur et à mesure des arrivées. Les agents voient les demandes en direct.
Astuce : Si la file d'un bureau est trop longue, utilisez "📢 Diffuser" pour prévenir l'agent qu'il peut appeler plus vite ou demander un renfort.
💙

Guide — Assistant·e Social·e

Ton agenda, ta file et ta coordination équipe — tout au même endroit.

📅

Agenda rendez-vous

Vues Jour, Semaine, Mois. Réservez un local, ajoutez un service et un agent. Les conflits sont détectés automatiquement.

🎫

Appel de ticket

Depuis votre bureau, appelez le prochain bénéficiaire en un clic. Il voit son numéro affiché sur l'écran public.

📤

Signaler un problème

Bouton "📤 Requête" → choisissez "Technique" ou "Entretien" pour prévenir les intervenants appropriés.

👥

Disponibilité collègues

Vue Direct → onglet Équipe. Vous voyez instantanément si un collègue est disponible pour un renvoi ou une coordination.

Ouvrir votre bureau

  1. Vue Direct → Mon bureauVotre rôle est lié à un bureau spécifique. Cliquez "Ouvrir bureau" pour signaler votre présence.
  2. Voir les tickets en attenteLe compteur sur votre carte bureau indique combien de personnes attendent. Appelez le suivant via le bouton "⬇️ Appeler".
  3. Fermer votre bureau en partantCliquez "Fermer bureau" à la fin de votre permanence. Les bénéficiaires ne seront plus dirigés vers votre local.
Rendez-vous récurrents : Créez un rendez-vous hebdomadaire ou mensuel en une seule action depuis le formulaire de réservation → section "Récurrence".

Guide — Technicien·ne

Gérez les demandes d'intervention technique et restez informé de l'état des locaux.

🛠️

Panneau Interventions

Bouton "🛠️ Interventions" dans le header. Vous y voyez toutes les demandes techniques qui vous sont adressées, triées par statut.

🙋

Prendre en charge

Cliquez "🙋 Je prends" pour vous assigner une intervention. L'agent demandeur reçoit une notification automatique.

✅

Terminer & reporter

Marquez une intervention comme terminée ou reportée. Le demandeur est notifié à chaque changement d'état.

💬

Commenter

Ajoutez un commentaire sur une intervention pour informer le demandeur de l'avancement ou poser une question.

Statuts d'une intervention

  1. 🟡 OuverteNouvelle demande — personne n'a encore pris en charge. Prenez-la ou assignez-la.
  2. 🔵 En coursVous avez pris en charge. Le demandeur sait que vous travaillez dessus.
  3. ⏸ ReportéeImpossible de traiter maintenant. Sera visible dans l'onglet "Reportées" pour ne pas l'oublier.
  4. ✅ TerminéeIntervention résolue. Le demandeur reçoit une notification de résolution.
Badge rouge sur 🛠️ : Indique le nombre de demandes ouvertes non prises en charge. Vérifiez régulièrement — surtout après une notification.

Guide — Agent·e d'entretien

Simple et rapide — voici l'essentiel pour votre quotidien.

🛠️

Interventions entretien

Les demandes d'entretien (nettoyage, aménagement) vous parviennent via le panneau "🛠️ Interventions". Vous ne voyez que les demandes de type "entretien".

📅

Planning

Consultez l'agenda pour voir les réservations de la journée — utile pour planifier le nettoyage des locaux selon leur occupation.

👥

Équipe présente

Voyez qui est là aujourd'hui. Utile pour savoir à qui s'adresser en cas de question ou pour coordonner une tâche.

🔔

Notifications

Vous recevez une alerte sonore quand une nouvelle demande d'entretien arrive. Vérifiez la cloche 🔔 en haut.

  1. Se connecter le matinOuvrez l'application, sélectionnez votre nom et entrez votre code.
  2. Vérifier les interventionsCliquez sur "🛠️ Interventions" — s'il y a un badge rouge, c'est qu'une nouvelle demande vous attend.
  3. Prendre en charge et traiterCliquez "🙋 Je prends", effectuez l'intervention, puis "✓ Terminée". L'agent demandeur est informé.

Guide — Administrateur

Configuration, gestion des agents et des paramètres de l'organisation.

👤

Gestion des agents

Paramètres → Agents. Ajoutez, renommez, changez le code ou le rôle d'un agent. Définissez des rôles personnalisés avec des permissions précises.

🏠

Configuration des lieux

Paramètres → Lieux. Créez des lieux avec leurs locaux, horaires d'ouverture et jours actifs.

🚩

Feature flags

Paramètres → Fonctionnalités. Activez/désactivez les modules (files d'attente, borne kiosk, push PWA, vue publique…) sans toucher au code.

🎫

Files d'attente

Paramètres → Files. Créez et configurez les groupes de files (nom, locaux associés). Chaque groupe a son propre préfixe de ticket.

🖥️

Écrans publics

Créez des écrans multi-vues pour l'affichage public. Chaque écran peut montrer un sous-ensemble de locaux.

🧹

Vider les locaux

Paramètres → section "Fin de journée" → bouton "Vider tous les locaux". Réinitialise toutes les présences en un clic.

Créer un nouvel agent

  1. Ouvrir les ParamètresBouton ⚙️ Paramètres dans le header. Accessible uniquement avec le rôle admin.
  2. Section "Agents"Entrez le nom complet de l'agent dans le champ et cliquez "Ajouter".
  3. Définir le codeDans la liste des agents, cliquez sur le cadenas 🔒 pour définir le code de l'agent.
  4. Assigner un rôleCliquez sur "Rôle" pour attribuer un rôle prédéfini ou personnalisé. Le rôle détermine les fonctionnalités visibles.
  5. Communiquer le code à l'agentTransmettez le code en personne ou par message sécurisé. L'agent peut se connecter immédiatement.
Sécurité : Ne partagez jamais les codes par email ou messagerie non sécurisée. Si un agent perd son code, réinitialisez-le depuis les Paramètres.
🖨️ Matériel : En tant qu'administrateur, vous êtes souvent l'interlocuteur du prestataire informatique. Consultez la section Matériel complémentaire pour connaître les équipements recommandés (imprimante Epson, écrans publics, borne kiosque) et préparer votre discussion avec l'intégrateur.
📅

Module — Agenda

Réserver un local, gérer les récurrences, voir les conflits

📋

Vue Jour

Grille horaire complète avec tous les locaux. Cliquez sur une case libre pour réserver. Les créneaux occupés s'affichent avec couleur agent.

📆

Vue Semaine

Vue condensée 5 jours. Cliquez sur un créneau pour ouvrir le formulaire de réservation sur ce jour.

🗓️

Vue Mois

Aperçu global avec indicateur coloré de disponibilité par jour. Cliquez sur un jour pour aller en vue Jour.

🔒

Permanences

Une réservation permanente bloque un local toute la journée. Elle apparaît en fond sombre et ne peut être écrasée qu'avec confirmation.

  1. Nouvelle réservationCliquez sur une case libre en vue Jour, ou sur "+ Réserver" dans le header.
  2. Remplir le formulaireLocal, service, agent, heure de début et fin. Ajoutez optionnellement un commentaire ou des agents invités.
  3. Récurrence (optionnel)Section "Récurrence" → Quotidien / Hebdomadaire / Mensuel. Définissez une date de fin si nécessaire.
  4. SauvegarderCliquez "Enregistrer". En cas de conflit, une boîte de dialogue vous propose de résoudre ou annuler.
🎫

Module — Files d'attente

Tickets, appels, flux de bénéficiaires

  1. Ouvrir votre bureauVue Direct → votre carte bureau → "Ouvrir bureau". Le bureau apparaît comme disponible pour l'accueil.
  2. Émission de ticketsL'accueil émet les tickets via Vue Direct → "Émettre un ticket" sur votre groupe de file. Le numéro apparaît sur l'écran public.
  3. Appel du prochainCliquez "⬇️ Appeler" sur votre carte bureau. Le bénéficiaire est appelé sur l'écran public avec un son.
  4. ClôtureEn fin de permanence, cliquez "Fermer bureau". Les bénéficiaires suivants seront redirigés vers les bureaux ouverts.
📋

Module — Vue Direct

🌐

Recherche agent

⏸
