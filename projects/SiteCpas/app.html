✨ Patch note v1.4.0 — 22 avril 2026
🛠️ Nouveau : Espace Responsable technique
  • Nouveau rôle "Responsable technique" disponible dans la gestion des rôles — il supervise les requêtes techniques et accède à une page dédiée avec des statistiques détaillées.
  • Thèmes d'intervention : chaque requête technique peut maintenant être catégorisée (Chauffage/Chaudière, Plomberie, Électricité, Serrurerie, Menuiserie, Peinture, Informatique, Mobilier, Sécurité/Alarme, Espaces verts, Nettoyage, Autre). L'admin peut ajouter/renommer/supprimer des thèmes dans Paramètres → 🏷️ Thèmes techniques.
  • Requêtes récurrentes : à la création d'une requête, coche "↻ Requête récurrente" pour la faire régénérer automatiquement tous les X jours / semaines / mois, avec date de fin optionnelle. Pratique pour les entretiens périodiques (ex: vérification chaudière tous les 6 mois).
  • Page /technique.html accessible via le bouton 🛠️ Espace technique du header (visible pour le Responsable technique et l'admin). Contient :
    • 4 KPIs : total requêtes, ouvertes, temps moyen de résolution, top thème.
    • Graphe temporel des créations sur la période.
    • Répartition par thème, par statut, top 10 locaux, charge par agent.
    • Requêtes en retard (ouvertes depuis > 7 jours).
    • Séries récurrentes actives avec prochaine occurrence.
    • Timeline des dernières requêtes.
    • Barre de recherche universelle + filtres période/statut.
    • Export CSV en un clic.
  • Badges dans le panneau Interventions : chaque requête affiche son thème 🏷️ et un badge ↻ pour les récurrentes. Bouton 🏷️ Catégoriser pour tagger les anciennes requêtes. Boutons Voir la série / Arrêter la série pour les templates récurrents.
📅 Refonte de la vue Jour (rappel v1.3.0)
  • Une colonne par local (au lieu d'une par desk). Les locaux avec plusieurs desks affichent ceux-ci en sous-lanes côte à côte : une résa sur un desk occupe 1/N de la largeur de la colonne du local.
  • Toggle « Vue compacte / Vue complète » (bouton dans la barre de date, à droite) :
    • Compacte — lignes à 36px, contenu condensé (svc + agent · heure).
    • Complète — hauteurs de ligne dynamiques : une ligne vide reste à 36px, mais s'épaissit automatiquement pour afficher tous les détails d'une résa (service, agent, heure, commentaire, invités) — même sur 30 minutes.
    Ton choix est mémorisé par navigateur.
  • Largeur des colonnes ajustable — survole la bordure droite d'un header de local puis glisse pour redimensionner ; double-clic pour revenir à 140px. Les largeurs sont persistées localement.
  • Scroll horizontal automatique quand il y a beaucoup de locaux — le tableau dépasse, la barre de date et les entêtes suivent.
  • Mode zoom — clique sur un toggle « Local X » au-dessus du calendrier pour zoomer sur un seul local : sa colonne s'élargit pour laisser ~140px par desk-lane. Badge 🔍 sur le header.
  • Colonne « 👤 Mon agenda » — largeur fixe, toujours accrochée à gauche à côté de la colonne des heures, peu importe le lieu sélectionné.
✍️ Widget « Partir en mission » — commentaire sans limite
  • Le champ « Destination / motif » n'est plus limité à 80 caractères. Écris autant que tu veux.
  • La zone s'étire en hauteur au fur et à mesure que tu tapes (multi-ligne).
🧹 Vider un local en un clic (rappel v1.2.2)
  • Bouton flottant 🧹 en bas à gauche pour l'agent d'accueil (et admin / chef de service).
  • Un clic ouvre la liste de tous les locaux groupés par lieu, avec les agents actuellement déclarés dans chacun.
  • Sélectionne un local → confirmation → toute la présence est retirée, le bureau est fermé et la file locale remise à zéro.
  • Pratique quand quelqu'un a oublié de quitter son bureau ou pour faire le ménage rapidement.
🔔 Appel direct d'un ticket de la file (v1.2.1)
  • Sur la carte de ton bureau (Vue Direct), chaque ticket en attente a maintenant un bouton cloche 🔔 à sa droite.
  • Un clic sur la cloche appelle directement ce ticket-là, sans respecter l'ordre FIFO. Pratique pour un bénéficiaire identifié, une urgence, un RDV…
  • Garde-fous : refus si ton bureau n'est pas ouvert ou s'il est déjà occupé (un message te l'explique).
💺 Nouveau : « Ce bureau sera bientôt pris »
  • Dans la modal « Demande agent spécifique », nouvelle case à cocher « 💺 Ce bureau sera bientôt pris ».
  • Si l'agent ciblé n'a pas encore ouvert de bureau, la demande reste en attente. Dès qu'il ouvre un bureau, elle est routée automatiquement avec émission du ticket SP.
  • Sur la Vue Direct de l'accueil, nouveau récap visuel « 🎫 Demandes en cours » et « 💺 En attente d'ouverture » pour suivre toutes les demandes SP d'un coup d'œil. Bouton ✕ pour annuler une demande en attente.
🎉 Calendrier de congés personnel (rappel v1.1.0)
  • Widget « Mes absences » sur l'écran d'accueil : déclare et gère tes congés/maladies/formations.
  • À la déclaration : détection auto des réservations existantes sur la période, avec option de les supprimer.
  • Indicateurs rouges sur Jour (bannière) / Semaine (soulignement) / Mois (rayures diagonales + 🌴).
  • Blocage strict à la création de réservation sur un jour d'absence.
🐛 Corrections
  • « Appeler le suivant » vs file avec SP : le système ignorait parfois le SP quand un ticket avait été appelé hors ordre juste avant (via la cloche). La comparaison saute maintenant les tickets déjà traités.
  • Panneau admin — Affichage des tickets : la ligne « Cartes groupe file » se synchronise correctement avec Firebase. Quand tout est décoché, le numéro de ticket n'apparaît plus en fallback (anonymisation respectée).
  • Widget « Partir en mission » : le champ texte ne se vide plus tout seul pendant la saisie.
  • Ticket nominatif : cliquer sur « Annuler » dans le prompt abandonne bien l'émission.
  • Inscription à une file d'attente (Vue Direct) : warning affiché + blocage si ton bureau n'est pas ouvert.
  • Modal « Demande agent spécifique » : labels au-dessus des champs, nom complet préservé (« Mr Roger » reste « Mr Roger »).
  • Vue Direct : carte du bureau actif accessible en scroll sur petit écran.
  • Vue Jour — colonnes étroites : texte des réservations plus coupé quand Windows est en mise à l'échelle 125 % ou plus.
✨ Améliorations UX
  • Widget « Me déclarer dans un bureau » : les bureaux déjà occupés par un autre agent sont maintenant marqués en 🔴 orange. Au survol, le nom de l'occupant s'affiche.
  • Vue Direct — cartes de groupe : le « Prochain créneau » affiche désormais l'heure de fin (ex : lun. 20/04 · 08:30 – 09:00).
